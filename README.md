# Agentes_IA

Repositório para desenvolvimento de agentes de IA, integrando SDKs e serviços como:

- Microsoft Foundry (Azure AI Foundry)
- OpenAI
- Azure AI Language (análise de texto)
- Azure AI Speech (fala)
- Azure AI Translator (tradutor)
- Azure AI Document Intelligence (informação de documentos)
- Azure AI Content Understanding (compreensão de conteúdos)
